# Command Relay

A local Windows workbench for AI-assisted development with explicit human control.

**Import → Review → Run → Copy**

Command Relay connects an AI chat to your local workflow through structured task and result packets, not direct access to your computer. It offers a Qt editor and terminal, evidence tools and local history. Review each script and export; it is not a sandbox.
